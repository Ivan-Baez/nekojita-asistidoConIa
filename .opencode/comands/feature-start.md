# 🚀 Instrucciones para Iniciar Feature

1. Lee el archivo `spec/constitution/roadmap.md` para identificar cuál es la siguiente feature pendiente.  
2. Abre la carpeta correspondiente en `spec/features/NNN-[nombre]/`.  
3. Revisa atentamente `spec.md`, `plan.md` y `tasks.md`.  
4. Muestra un resumen en consola indicando:  
   - Nombre de la feature.  
   - Estado de las tareas pendientes (`- [ ]`).  
   - Primera tarea que se va a ejecutar.
