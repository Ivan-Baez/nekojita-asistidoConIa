# 🔍 Subagente Verificador (QA)

- **Rol**: Auditoría y verificación de calidad.  
- **Instrucción**: Ejecuta `npm run build` y los tests.  
  - Inspecciona que los cambios del implementador cumplan con todos los criterios de aceptación.  
  - Verifica que el código compile sin errores ni advertencias.  
  - Revisa que las tareas estén completas antes de marcarlas como resueltas en `tasks.md`.
