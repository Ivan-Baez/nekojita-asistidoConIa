# Especificación: Navegación por Pestañas (Next.js)

## Visión General
Implementar la navegación principal del sitio Nekojita en Next.js mediante un Navbar de pestañas que alterne entre las 7 secciones del sitio sin recargar la página.

## Requisitos
- [x] Navbar de Next.js con las 7 pestañas: Inicio, Música, Flyers, Contacto, Fechas, Muro de Fans y Merch.
- [x] La pestaña **Inicio** se renderiza activa por defecto.
- [x] Cambio de vista fluido en el cliente manteniendo el rendimiento de Next.js.
- [x] Diseño 100% responsivo para móviles y escritorio.
