# Especificación: Secciones Públicas (Next.js)

## Visión General
Desarrollar e integrar los componentes de UI para las 7 secciones/pestañas públicas de la web de Nekojita utilizando componentes de React en Next.js.

## Criterios de Aceptación por Sección

- [ ] **1. Inicio (Hero):**
  - Reproductor de video integrado con el recital en Santiago de Chile.
  - Contenedor dinámico preparado para recibir el carrusel de eventos.

- [ ] **2. Música:**
  - Tarjetas de reproducción de los 3 singles con sus letras.
  - Botones con estética de cassette para escuchar y descargar los temas.

- [ ] **3. Flyers:**
  - Galería/Grid interactivo de afiches desordenados respetando la estética punk.

- [ ] **4. Contacto:**
  - Formulario de contacto funcional.
  - Botón de descarga de la gacetilla de prensa (PDF/documento).

- [ ] **5. Fechas:**
  - Iframe responsivo de Google Calendar embebido.

- [ ] **6. Muro de Fans:**
  - Integración de Google Forms embebido para mensajes de la comunidad.

- [ ] **7. Merch:**
  - Vista de productos/remeras con aviso promocional **“Próximamente”**.
