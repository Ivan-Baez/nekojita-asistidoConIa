# 🗺️ Roadmap Global de Implementación

1. **`001-navegacion-pestanas`**: Sistema de pestañas y Navbar en Next.js.  
2. **`002-secciones-publicas`**: Maquetado de las 7 pestañas públicas (Hero video, Música/Cassettes, Flyers, Contacto, Fechas, Muro, Merch).  
3. **`003-backend-auth-db`**: API NestJS, conexión a PostgreSQL con Prisma y Login JWT.  
4. **`004-dashboard-carrusel`**: Dashboard privado en Next.js, formulario de eventos y carrusel dinámico en la Home.
